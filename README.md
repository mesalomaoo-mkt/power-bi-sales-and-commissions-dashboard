💼 Power BI Sales and Commissions Dashboard
 
## Overview
 
This Power BI dashboard was developed to analyze sales performance, commissions, and revenue distribution across different sales statuses.
 
## Business Objectives
 
- Monitor gross and net sales
- Track commission performance
- Analyze revenue by status
- Evaluate monthly commission trends
- Support commercial decision-making
 
## Tools Used
 
- Power BI
- Power Query
- DAX
- Data Modeling
 
## Key KPIs
 
- Gross Sales Value
- Total Commissions
- Net Revenue
- Revenue by Status
- Monthly Commission Analysis
 
## Dashboard Features
 
- Sales performance monitoring
- Revenue status breakdown
- Monthly commission tracking
- Revenue distribution analysis
- Financial KPI management
